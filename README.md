# Andrei Romanov

Engineer in Belgrade, Serbia. Years of DevOps and cloud infrastructure work; these days I mostly write Rust: Linux desktop and audio tools, terminal apps, and tooling that keeps AI coding agents productive.

I like tools that do one job, stay out of the way, and never take an action they can't undo.

## 👷 Currently working on

- [ansromanov/onedrive-gui](https://github.com/ansromanov/onedrive-gui) - Windows-style tray app, settings and Dolphin sync marks for abraunegg/onedrive (today)
- [ansromanov/mantis](https://github.com/ansromanov/mantis) - A fast terminal file tree viewer with syntax highlighting, markdown rendering, fuzzy search, and mouse support. (today)
- [ansromanov/moncenter](https://github.com/ansromanov/moncenter) - Gaming-style DDC/CI monitor control panel for Linux (ddcutil + Qt/QML) (1 day ago)
- [ansromanov/lineworker](https://github.com/ansromanov/lineworker) - Keeps your pull requests moving: finds the stuck ones, repairs what it safely can, never merges (3 days ago)
- [ansromanov/chappe](https://github.com/ansromanov/chappe) - The coordination chat for AI agents building things together (3 days ago)
