# Hi, I'm Andrei Romanov 👋

Engineer based in Belgrade, Serbia. I started out in infrastructure and cloud automation and these days mostly write Rust: Linux desktop and audio tools, terminal apps, and tooling for AI coding agents.

🌐 [andreiromanov.dev](https://andreiromanov.dev)

## What I'm building

**Developer tools & AI agents**
- [**chappe**](https://github.com/ansromanov/chappe): a coordination chat for AI agents building things together. A quiet message bus for Claude Code, Codex and others, with a session registry and Gitea/GitHub/GitLab webhooks.
- [**lineworker**](https://github.com/ansromanov/lineworker): keeps pull requests moving. It finds stuck ones and repairs what it safely can, but never merges.
- [**mantis**](https://github.com/ansromanov/mantis): a fast terminal file tree viewer with syntax highlighting, markdown rendering, fuzzy search and mouse support.

**Linux desktop & audio**
- [**wireaudio**](https://github.com/ansromanov/wireaudio): a CoreAudio-style low-latency ALSA studio engine with a multi-client shared audio bus and a desktop control center.
- [**moncenter**](https://github.com/ansromanov/moncenter): a gaming-style DDC/CI monitor control panel (ddcutil + Qt/QML).
- [**onedrive-gui**](https://github.com/ansromanov/onedrive-gui): a Windows-style tray app, settings and Dolphin sync marks for abraunegg/onedrive.

**Libraries & utilities**
- [**tabslib-rs**](https://github.com/ansromanov/tabslib-rs): a general-purpose tablature library for Rust with an immutable document model, format codecs and deterministic edits.
- [**serbian-split-translator**](https://github.com/ansromanov/serbian-split-translator): a bilingual reader for Chrome and Edge that translates Serbian (Latin and Cyrillic) into Russian or English.
